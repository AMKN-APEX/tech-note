# 技術雑学アプリ 設計書（v0.1）

## 目的
- 世の中の技術を分野を問わず理解し、人に話せるようになる
- 知識が「つながっていく」感覚を持つ
- 読むだけでなく、思い出す・予想する・説明することで考える力を鍛える

## 利用シーン
- スマホで通勤中、1日約10分
- 利用者は自分ひとり

## 1日の流れ（約10分）
| 時間 | 内容 |
|---|---|
| 約1分 | 今日の基礎用語カード（新しい話題の前提となる用語） |
| 約4分 | 新しい話題2本（下記の構成） |
| 約5分 | 復習3〜5問（間隔反復、用語カードと話題カードの両方） |

### 話題1本の構成
1. **予想の問い**：「なぜだと思う？」に、答えを見る前に一度考える（考える力のため）
2. **要点3行**
3. **仕組み**：なぜそうなるのか（3〜5段階の流れ図＋文章）
4. **基礎用語**：前提となる用語（既に覚えたものには「既習」と表示）
5. **つながり**：過去に学んだ話題や用語との関係
6. **話のネタ1行**：会話で使える形の一言
7. **写真**：元記事の代表画像（og:image）を元記事のURLから直接表示する。リポジトリには保存しない（著作権のため）
8. **動画**：YouTube検索ボタン（AIが検索キーワードを決める）。通勤後に見る追加枠

## 対象分野
- 技術なら何でも。最近のニュースを起点にする
- 偏りすぎないよう生成時に調整する
- 背景：AI（得意分野、深掘り）、機械・物理（専攻）、化学（勤務先の分野だが専門外。基礎から学ぶ）

## 構成（方式A：Claude Codeの定期実行）
```
[毎朝：Claude Code ルーティン（Pro契約の範囲内）]
  1. Pythonスクリプトで RSS を取得 → 候補記事一覧
  2. Claude が話題を2本選び、カードを生成（既習の用語一覧を参照）
  3. スキーマ検証（Python）→ data/ にJSONで保存 → GitHubにpush

[スマホ：PWA（GitHub Pages）]
  data/*.json を読み込んで表示
  復習スケジュールは ts-fsrs で計算し、端末の localStorage に保存（エクスポート機能つき）
```

- 生成処理は「入力：候補記事＋既習用語 → 出力：カードJSON」という形に閉じ込める。2027年8月にPro契約が切れたら、ここだけをClaude APIに差し替えられるようにする
- GitHub Pages を無料で使うため、リポジトリは公開する（中身はニュースの要約のみ）

## データ（案）
- `data/days/YYYY-MM-DD.json`：その日の話題カードと用語カード
- `data/terms.json`：用語辞書（用語、やさしい定義、初出日、関連する話題）
- 復習の状態：スマホの localStorage（MVPの段階）

## フェーズ
- **MVP**：RSS取得 → カード生成 → PWAで閲覧・予想・復習
- **フェーズ2**：説明チャレンジ（スマホで回答 → 翌朝の実行でまとめて添削）
- **フェーズ3**：つながりの可視化（用語と話題のネットワーク図）、復習状態のクラウド同期
